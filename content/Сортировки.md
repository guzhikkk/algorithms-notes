# 📊 Алгоритмы сортировки

**Сортировка** — это процесс перестановки элементов множества в определенном порядке для облегчения последующего поиска.

> [!info] Ключевые характеристики сортировок
> - **Устойчивость (стабильность):** порядок элементов с одинаковыми ключами не меняется при сортировке.
> - **In-place («на том же месте»):** алгоритм не выделяет $O(n)$ дополнительной памяти, а делает перестановки (swap) прямо в исходном массиве. In-place алгоритмы предпочтительнее.

## 1. Пузырьковая сортировка (Bubble Sort)
![[bubble_sort.gif]]

Осуществляет проходы по списку от начала к концу. Два соседних элемента сравниваются, и если они стоят неверно — переставляются. Каждый раз самый большой элемент «всплывает» в конец, как пузырек.

- **Сложность:** $O(n^2)$
- **Память:** $O(1)$ (in-place)
- **Устойчивость:** ✅ Устойчивая

**Плюсы и минусы:**
- ➕ **Плюсы:** Легко написать. Можно оптимизировать: если за проход не было обменов, значит массив уже отсортирован.
- ➖ **Минусы:** Очень медленная на больших данных, делает огромное количество перестановок.

**Пример из жизни:** Школьники строятся на физкультуре по росту. Учитель идет вдоль строя: если стоящий слева ученик выше того, что справа, он меняет их местами. К концу строя самый высокий точно окажется последним.

### Реализация

**Python:**
```python title="bubble_sort.py"
def bubble_sort(arr):
    n = len(arr)
    for iter in range(n - 1):
        swapped = False
        for i in range(n - iter - 1):
            if arr[i] > arr[i + 1]:
                arr[i], arr[i + 1] = arr[i + 1], arr[i]
                swapped = True
        if not swapped:
            break
```

**C++:**
```cpp title="bubble_sort.cpp"
#include <vector>
#include <algorithm>

void bubbleSort(std::vector<int>& arr) {
    int n = arr.size();
    for (int iter = 0; iter < n - 1; ++iter) {
        bool swapped = false;
        for (int i = 0; i < n - iter - 1; ++i) {
            if (arr[i] > arr[i + 1]) {
                std::swap(arr[i], arr[i + 1]);
                swapped = true;
            }
        }
        if (!swapped) break;
    }
}
```

## 2. Сортировка простым выбором (Selection Sort)
*Место для гифки: `![[selection_sort.gif]]`*

Находит элемент с наименьшим значением и меняет его местами с первым. Затем ищет минимум из оставшихся и ставит на второе место, и так далее.

- **Сложность:** $O(n^2)$
- **Память:** $O(1)$ (in-place)
- **Устойчивость:** ❌ Не устойчивая

**Плюсы и минусы:**
- ➕ **Плюсы:** Делает минимальное количество обменов элементов по сравнению с пузырьком.
- ➖ **Минусы:** Время работы всегда $O(n^2)$, даже если массив изначально отсортирован.

**Пример из жизни:** Вы хотите отсортировать песни в плейлисте от самой короткой к самой длинной. Вы просматриваете весь список, находите самый короткий трек и переносите его в самый верх. Потом ищете самый короткий из оставшихся и ставите вторым.

### Реализация

**Python:**
```python title="selection_sort.py"
def selection_sort(arr):
    n = len(arr)
    for i in range(n - 1):
        key = arr[i]
        ind = i
        for j in range(i + 1, n):
            if arr[j] < key:
                key = arr[j]
                ind = j
        if i != ind:
            arr[i], arr[ind] = arr[ind], arr[i]
```

**C++:**
```cpp title="selection_sort.cpp"
#include <vector>
#include <algorithm>

void selectionSort(std::vector<int>& arr) {
    int n = arr.size();
    for (int i = 0; i < n - 1; ++i) {
        int min_ind = i;
        for (int j = i + 1; j < n; ++j) {
            if (arr[j] < arr[min_ind]) {
                min_ind = j;
            }
        }
        if (i != min_ind) {
            std::swap(arr[i], arr[min_ind]);
        }
    }
}
```

## 3. Сортировка простыми вставками (Insertion Sort)
*Место для гифки: `![[insertion_sort.gif]]`*

Массив условно делится на упорядоченную и входную части. Берется элемент из входной части и вставляется в подходящее место готовой последовательности (элементы, которые больше, сдвигаются вправо).

- **Сложность:** $O(n^2)$
- **Память:** $O(1)$ (in-place)
- **Устойчивость:** ✅ Устойчивая

**Плюсы и минусы:**
- ➕ **Плюсы:** Метод очень эффективен, когда нужно внести небольшие изменения в уже отсортированный массив. Быстро работает на почти отсортированных данных.
- ➖ **Минусы:** В худшем случае (массив отсортирован в обратном порядке) придется долго сдвигать элементы.

**Пример из жизни:** Раскладывание карт в руке. Вы берете новую карту из колоды и вставляете её в свой уже отсортированный веер карт на нужное место.

### Реализация

**Python:**
```python title="insertion_sort.py"
def insertion_sort(arr):
    n = len(arr)
    for i in range(1, n):
        key = arr[i]
        j = i
        while j >= 1 and arr[j - 1] > key:
            arr[j] = arr[j - 1]
            j -= 1
        arr[j] = key
```

**C++:**
```cpp title="insertion_sort.cpp"
#include <vector>

void insertionSort(std::vector<int>& arr) {
    int n = arr.size();
    for (int i = 1; i < n; ++i) {
        int key = arr[i];
        int j = i;
        while (j >= 1 && arr[j - 1] > key) {
            arr[j] = arr[j - 1];
            j--;
        }
        arr[j] = key;
    }
}
```

## 4. Сортировка слиянием (Merge Sort)
*Место для гифки: `![[merge_sort.gif]]`*

Работает по принципу «разделяй и властвуй». Массив рекурсивно делится на две половины вплоть до единичных элементов, затем эти половины сливаются в правильном порядке.

- **Сложность:** $O(n \log n)$
- **Память:** $O(n)$ (not in-place)
- **Устойчивость:** ✅ Устойчивая

**Плюсы и минусы:**
- ➕ **Плюсы:** Всегда работает быстро, гарантированное $O(n \log n)$. Отлично подходит для огромных массивов, которые не помещаются в оперативную память.
- ➖ **Минусы:** Требует дополнительную память $O(n)$ для слияния.

**Пример из жизни:** Сортировка огромной папки с документами. Вы делите папку пополам и отдаете половину коллеге. Вы сортируете свою стопку, он — свою. Потом вы берете две отсортированные стопки и сливаете их в одну, сравнивая только верхние листы.

### Реализация

**Python:**
```python title="merge_sort.py"
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    ind = len(arr) // 2
    left = merge_sort(arr[:ind])
    right = merge_sort(arr[ind:])
    
    res = []
    i, j = 0, 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            res.append(left[i])
            i += 1
        else:
            res.append(right[j])
            j += 1
    res.extend(left[i:])
    res.extend(right[j:])
    return res
```

**C++:**
```cpp title="merge_sort.cpp"
#include <vector>

void merge(std::vector<int>& left, std::vector<int>& right, std::vector<int>& arr) {
    int i = 0, j = 0, k = 0;
    while (i < left.size() && j < right.size()) {
        if (left[i] <= right[j]) arr[k++] = left[i++];
        else arr[k++] = right[j++];
    }
    while (i < left.size()) arr[k++] = left[i++];
    while (j < right.size()) arr[k++] = right[j++];
}

void mergeSort(std::vector<int>& arr) {
    if (arr.size() <= 1) return;
    int mid = arr.size() / 2;
    std::vector<int> left(arr.begin(), arr.begin() + mid);
    std::vector<int> right(arr.begin() + mid, arr.end());
    
    mergeSort(left);
    mergeSort(right);
    merge(left, right, arr);
}
```

## 5. Быстрая сортировка (Quick Sort)
*Место для гифки: `![[quick_sort.gif]]`*

Разбивает массив на две части относительно опорного (барьерного) элемента: слева те, что меньше опорного, справа — те, что больше (partition). Затем рекурсивно сортирует каждую из частей.

- **Сложность:** $O(n \log n)$ в среднем, но $O(n^2)$ в худшем случае.
- **Память:** $O(\log n)$ на стек вызовов рекурсии (in-place).
- **Устойчивость:** ❌ Не устойчивая

**Плюсы и минусы:**
- ➕ **Плюсы:** На практике является одним из самых быстрых алгоритмов. Не требует $O(n)$ дополнительной памяти.
- ➖ **Минусы:** Может деградировать до $O(n^2)$, если опорный элемент выбирается неудачно.

**Пример из жизни:** Сортировка книг на полке. Вы выбираете случайную книгу. Все книги тоньше неё ставите слева, а толще — справа. Затем повторяете этот же трюк отдельно для левой стопки и для правой.

### Реализация

**Python (in-place):**
```python title="quick_sort.py"
from random import randint

def quick_sort(arr, left, right):
    if left < right:
        val = arr[randint(left, right)]
        l, r = left, right
        while l <= r:
            while arr[l] < val:
                l += 1
            while arr[r] > val:
                r -= 1
            if l <= r:
                arr[l], arr[r] = arr[r], arr[l]
                l += 1
                r -= 1
        if left < r:
            quick_sort(arr, left, r)
        if right > l:
            quick_sort(arr, l, right)
```

**C++ (in-place):**
```cpp title="quick_sort.cpp"
#include <vector>
#include <algorithm>
#include <cstdlib>

void quickSort(std::vector<int>& arr, int left, int right) {
    if (left >= right) return;
    
    int pivot = arr[left + rand() % (right - left + 1)];
    int l = left;
    int r = right;
    
    while (l <= r) {
        while (arr[l] < pivot) l++;
        while (arr[r] > pivot) r--;
        if (l <= r) {
            std::swap(arr[l], arr[r]);
            l++;
            r--;
        }
    }
    
    if (left < r) quickSort(arr, left, r);
    if (l < right) quickSort(arr, l, right);
}
```

## 6. Сортировка подсчетом (Counting Sort)
*Место для гифки: `![[counting_sort.gif]]`*

Используется для дискретных данных в небольшом диапазоне. Заводится массив-счетчик, куда записывается частота появления каждого числа. Затем исходный массив перезаписывается с учетом этих частот.

- **Сложность:** $O(n + k)$
- **Память:** $O(k)$ (дополнительная)
- **Устойчивость:** ✅ Устойчивая

**Плюсы и минусы:**
- ➕ **Плюсы:** Работает за линейное время, не использует операции сравнения элементов.
- ➖ **Минусы:** Требует много памяти, если диапазон чисел огромный. Работает только с целыми числами.

**Пример из жизни:** Подсчет голосов на выборах. Вместо того чтобы выкладывать бюллетени по порядку, вы просто заводите по коробке для каждого кандидата, кидаете туда голоса, а потом записываете, в какой коробке сколько штук.

### Реализация

**Python:**
```python title="counting_sort.py"
def counting_sort(arr):
    if not arr: return
    k = max(arr)
    counter = [0] * (k + 1)
    for x in arr:
        counter[x] += 1
        
    arr[:] = []
    for num in range(k + 1):
        arr += [num] * counter[num]
```

**C++:**
```cpp title="counting_sort.cpp"
#include <vector>
#include <algorithm>

void countingSort(std::vector<int>& arr) {
    if (arr.empty()) return;
    int k = *std::max_element(arr.begin(), arr.end());
    std::vector<int> counter(k + 1, 0);
    
    for (int x : arr) {
        counter[x]++;
    }
    
    arr.clear();
    for (int num = 0; num <= k; ++num) {
        for (int i = 0; i < counter[num]; ++i) {
            arr.push_back(num);
        }
    }
}
```

## 7. Инверсии (Inversions) и их связь с сортировками

**Инверсия** — это пара ключей (элементов массива) с нарушением правильного порядка следования. Формально это пара индексов $i$ и $j$ такая, что $i < j$, но $a[i] > a[j]$. 

В полностью отсортированном массиве количество инверсий равно нулю.

> [!info] Для чего нужно знать количество инверсий?
> - **Оценка "неупорядоченности":** Количество инверсий показывает, насколько сильно массив далек от отсортированного состояния.
> - **Связь с сортировками:** Перестановка двух соседних элементов, расположенных в неверном порядке, уменьшает количество инверсий ровно на 1. Следовательно, максимальное количество обменов для любой сортировки конечно и не превосходит изначального числа инверсий.

### Как посчитать количество инверсий?

#### Способ 1. «В лоб» (Сложность: $O(n^2)$)
Перебираем все возможные пересекающиеся пары элементов с помощью двух вложенных циклов и проверяем условие.

**Python:**
```python title="inversions_naive.py"
def number_of_inversions(arr):
    n = len(arr)
    ans = 0
    for i in range(n - 1):
        for j in range(i + 1, n):
            if arr[i] > arr[j]:
                ans += 1
    return ans
```

#### Способ 2. Через сортировку слиянием (Сложность: $O(n \log n)$)
Для больших массивов задачу можно решить намного быстрее, модифицировав сортировку слиянием. 

**Логика работы:** При слиянии левой и правой половин мы сравниваем два элемента. Ровно в тот момент, когда мы добавляем число из *левой* половины в итоговый массив, указатель правой половины (`j`) показывает на первое число, которое больше нашего. Это значит, что наше левое число уже обогнало `j` элементов из правой половины — прибавляем это значение к ответу.

**Python:**
```python title="inversions_merge.py" {13, 20}
inv = 0  # Глобальный счетчик инверсий

def merge(left, right):
    global inv
    res = []
    i, j = 0, 0
    
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            res.append(left[i])
            i += 1
            inv += j  # Учитываем инверсии для левого элемента
        else:
            res.append(right[j])
            j += 1
            
    if i < len(left):
        res.extend(left[i:])
        inv += len(left[i:]) * j  # Инверсии для оставшихся элементов слева
        
    if j < len(right):
        res.extend(right[j:])
        
    return res
