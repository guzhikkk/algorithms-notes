## Что такое О-нотация

Временная **сложность алгоритма** — это функция времени $T(n)$ от размера входных данных $n$, которая однозначно определяется числом выполняемых операций. Асимптотическая сложность определяет порядок времени роста алгоритма.

Для описания порядка времени роста используется **О-нотация (Big O)** — математическая запись, которая позволяет учитывать только наиболее весомые элементы функции времени. О-нотация дает верхнюю оценку, то есть показывает время выполнения алгоритма в худшем случае. 

Формальное определение: время работы алгоритма $T(n)$ имеет порядок роста $g(n)$ (обозначается как $T(n) = O(g(n))$), если существуют натуральное число $n_0$ и положительная константа $c$, такие что для любого $n \ge n_0$ выполняется неравенство $T(n) \le c \cdot g(n)$. Проще говоря, функция растет не быстрее, чем $g(n)$, с точностью до множителя.

## Правила вычисления времени выполнения

При оценке сложности написанного кода применяются следующие базовые правила:

1. **Правило отбрасывания констант:** постоянные множители не имеют значения для определения порядка сложности: $O(k \cdot g_1(n)) = O(g_1(n))$.
2. **Правило суммы:** для двух последовательных фрагментов кода берется максимальная сложность: $T_1(n) + T_2(n) = O(\max(g_1(n), g_2(n)))$.
3. **Правило произведения:** для двух вложенных фрагментов (например, циклов) их сложности перемножаются: $T_1(n) \cdot T_2(n) = O(g_1(n) \cdot g_2(n))$.
4. **Базовые операции:** время выполнения операторов присваивания, чтения, записи и сравнения пропорционально единице, то есть $O(1)$.
5. **Условные операторы:** сложность ветвления состоит из времени проверки условия и максимального времени выполнения одной из веток: $O(\text{if-then-else}) = O(\text{if}) + O(\max(\text{then}, \text{else}))$.
6. **Циклы:** вычисляется как произведение количества итераций цикла на наибольшее время выполнения тела цикла.

## Примеры расчета сложности

Анализ асимптотики на примерах реального кода:

**Линейная сложность — $O(n)$**
Размер данных прямо влияет на количество итераций (например, один проход по массиву).
```python
def calc_arr(arr):
    sm = 0
    for i in range(len(arr)):
        sm += arr[i]
    return sm
```

**Квадратичная сложность — $O(n^2)$**
Возникает при использовании двух вложенных циклов, каждый из которых зависит от размера $n$.
```python
def calculation(n):
    for i in range(n):
        for j in range(n):
            print(i + j)
```

**Кубическая сложность — $O(n^3)$**
Три вложенных цикла.
```python
def calc(n):
    for i in range(n):
        for j in range(n):
            for k in range(n):
                print(i + j + k)
```

**Логарифмическая сложность — $O(\log n)$**
Характерна для алгоритмов, где на каждом шаге количество оставшихся элементов делится пополам.
```python
def iteration(n):
    i = n
    while i > 0:
        i = i // 2
```

## Основные классы сложности и примеры алгоритмов

Понимание О-нотации позволяет сравнивать алгоритмы между собой. В качестве классического примера обычно приводятся различные [[Сортировки]].

* **$O(1)$ (константная):** найти последний элемент в массиве или минимум в отсортированном массиве.
* **$O(\log n)$ (логарифмическая):** бинарный поиск.
* **$O(n)$ (линейная):** поиск минимума в неотсортированном массиве или расчет суммы элементов.
* **$O(n \log n)$ (линейно-логарифмическая):** быстрая сортировка.
* **$O(n^2)$ (квадратичная):** базовые алгоритмы (сортировка выбором или пузырьком).
* **$O(2^n)$ (экспоненциальная):** рекурсивный расчет $n$-го числа Фибоначчи.
* **$O(n!)$ (факториальная):** задача о коммивояжере.
